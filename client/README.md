# Premier Medical Hospital Portal

A full-stack hospital management system built with React, Node.js, Express, and PostgreSQL.

## Overview

Premier Medical is a healthcare portal designed to simulate a modern hospital website and patient management system.

Patients can:
- View appointments
- Access medical results
- Manage their profile

Doctors can:
- View patient information
- Manage appointments
- Upload medical notes and results

Administrators can:
- Manage users
- Manage departments
- Monitor system activity
